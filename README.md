# Anti-Theft-Locker-Solar-Hybrid-Piso-Vendo-Phone-Charging
This is our prototype, a piso vendo phone charging that has a locker for storing smartphones when charging using a fingerprint sensor. This prevents theft, and also protects the system tampering to get stored coins inside the box using a vibration sensor.
